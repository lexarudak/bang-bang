# Сайт-визитка · Мария Сокирко

Одностраничный сайт-визитка врача-косметолога. Прокрутка переключает четыре
полноэкранные «обложки»; каждая смена фона — своя геометрическая маска. По кнопке
происходит взрыв.

**Сборки нет.** Сайт — это один файл `site/index.html`: фотографии и звук вшиты
в него как base64, внешних зависимостей нет, кроме Google Fonts. Его можно
открыть двойным щелчком, залить на любой хостинг или отдать целиком.

**Превью:** https://claude.ai/code/artifact/8e38afec-2220-4958-b2bc-f8a7ac3d6ee1

## Структура

```
site/index.html    сам сайт — правится здесь, он же и деплоится
assets/photos/     исходные фотографии
assets/sound/      исходный звук взрыва
serve.mjs          локальный просмотр с автоперезагрузкой (необязателен)
```

`assets/` в сайт не подгружается — это исходники, из которых сделано вшитое
содержимое. Нужны, только когда что-то меняешь.

## Локально

```bash
node serve.mjs          # http://localhost:8787
PORT=3000 node serve.mjs
```

Правишь `site/index.html`, сохраняешь — вкладка перезагружается сама.
Без сервера тоже работает: просто открой `site/index.html` в браузере.

## Деплой

Заливаешь `site/index.html` на хостинг — всё. Настроены два автоматических пути,
оба без сборки:

- **Netlify** — `netlify.toml` отдаёт папку `site` как есть.
- **GitHub Pages** — `.github/workflows/deploy.yml` публикует ту же папку при
  push в `main`. Свой домен задаётся переменной `SITE_BASE` в
  Settings → Secrets and variables → Actions → Variables.

Для превью ссылки в Telegram уже есть `og:title` и `og:description`. Картинку в
превью добавит строка с абсолютным адресом — её можно вписать, когда домен станет
известен:

```html
<meta property="og:image" content="https://твой-домен.ru/og.jpg" />
```

## Что где править

**Палитра** — блок `:root` в начале файла:

```css
--coal: #19191f;      /* 1-я обложка, кнопка взрыва, текст на светлом */
--cream: #f3ede3;     /* 2-я обложка, текст на тёмном */
--electric: #f08798;  /* 3-я обложка */
--coral: #f3ede3;     /* 4-я обложка */
```

От них зависят фоны, цвет текста, полоса прокрутки и полотно, которое прогорает
при взрыве. Не завязаны: подложка под фото, затемнение сцены во время взрыва и
кнопка взрыва под курсором — правятся вручную.

Рядом `LIGHT_GROUND = [false, true, false, true]` — какие обложки считаются
светлыми. От этого зависит цвет полосы прокрутки и текста. Меняешь тёмную
обложку на светлую — поменяй и здесь, и класс `cover--dark`/`cover--light`
в разметке.

**Темп прокрутки** — три места рядом:

- `height: 560vh` у `.scroller` — общая длина хода;
- `T` и `C` — окна, в которых идут шторы и приходят-уходят обложки;
- `ANCHORS` — точки, к которым прилипает прокрутка после остановки.

**Фотографии** вшиты в массив `PHOTOS`. Заменить:

```bash
sips -Z 900 -s format jpeg -s formatOptions 62 assets/photos/1.jpg --out /tmp/1.jpg
base64 -i /tmp/1.jpg
```

Первая идёт на вторую обложку, остальные — в карусель на третьей.

**Звук взрыва** — константа `BOOM_MP3`, туда же base64 от нового mp3.

**Тексты** — прямо в разметке обложек.
