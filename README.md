# Сайт-визитка · Мария Сокирко

Одностраничный сайт-визитка врача-косметолога. Прокрутка переключает четыре
полноэкранные «обложки»; каждая смена фона — своя геометрическая маска. По кнопке
происходит взрыв.

**Сборки нет.** Сайт — это один файл `index.html`: фотографии и звук вшиты
в него как base64, внешних зависимостей нет, кроме Google Fonts. Его можно
открыть двойным щелчком, залить на любой хостинг или отдать целиком.

**Превью:** https://claude.ai/code/artifact/8e38afec-2220-4958-b2bc-f8a7ac3d6ee1

## Структура

```
index.html         сам сайт — правится здесь, он же и деплоится
assets/photos/     исходные фотографии
assets/sound/      исходный звук взрыва
serve.mjs          локальный просмотр с автоперезагрузкой (необязателен)
```

`assets/` в сайт не подгружается — это исходники, из которых сделано вшитое
содержимое. Нужны, только когда что-то меняешь.

## Локально

```bash
node serve.mjs          # http://localhost:8787
PORT=3000 node serve.mjs
```

Правишь `index.html`, сохраняешь — вкладка перезагружается сама.
Без сервера тоже работает: просто открой `index.html` в браузере.

## Деплой

Заливаешь `index.html` на хостинг — всё. Настроены два автоматических пути,
оба без сборки:

- **Netlify** — `netlify.toml` отдаёт репозиторий как есть.
- **GitHub Pages** — `.github/workflows/deploy.yml` публикует его же при
  push в `main`. Свой домен задаётся переменной `SITE_BASE` в
  Settings → Secrets and variables → Actions → Variables.

Домен — **https://sokirko.doctor**, он прописан в мета-тегах и в файле `CNAME`.
Рядом с индексом лежат:

- `og.jpg` — карточка превью 1200×630 для Telegram и соцсетей;
- `apple-touch-icon.png` — иконка для экрана «Домой» на iOS;
- `robots.txt`, `sitemap.xml`, `CNAME`.

Карточка `og.jpg` собрана из первой фотографии и имени в шрифте сайта. Если
захочется её переснять — исходник карточки в истории задач, либо проще
пересобрать вручную под нужный кадр.

## Что где править

**Палитра** — блок `:root` в начале файла:

```css
--coal: #19191f;      /* 1-я обложка, кнопка взрыва, текст на светлом */
--cream: #f3ede3;     /* 2-я обложка, текст на тёмном */
--electric: #f08798;  /* 3-я обложка */
--coral: #f3ede3;     /* 4-я обложка */
```

От них зависят фоны, цвет текста, полоса прокрутки и полотно, которое прогорает
при взрыве. Не завязаны: подложка под фото, затемнение сцены во время взрыва и
кнопка взрыва под курсором — правятся вручную.

Рядом `LIGHT_GROUND = [false, true, false, true]` — какие обложки считаются
светлыми. От этого зависит цвет полосы прокрутки и текста. Меняешь тёмную
обложку на светлую — поменяй и здесь, и класс `cover--dark`/`cover--light`
в разметке.

**Темп прокрутки** — прокрутка обычная, системная, без прилипаний и доводки.
Настраивается в трёх местах:

- `height: 440vh` у `.scroller` — общая длина хода, сейчас 3.4 экрана;
- `smooth += (target - smooth) * 0.16` в `loop` — насколько картинка отстаёт от
  пальца; больше значение — резче отклик, меньше — тягучее;
- `outR` в массиве `C` — окно, в котором обложка уходит и открывает следующую.
  Сейчас переход занимает 0.24 хода, пауза между переходами — 0.08. Холостая
  прокрутка при этом около трети; была 61%, когда переходы были вдвое короче.

**Как устроены переходы.** Обложки — это четыре самостоятельных экрана со своим
фоном, сложенных стопкой: первая сверху, четвёртая снизу. Переход не приносит
новый фон поверх старого, а снимает верхнюю обложку — под ней уже собрана
следующая целиком. Поэтому не бывает ни наложения двух обложек, ни пустого фона
без содержимого.

Снимаются они функцией `peel`, формы разные: косой срез, растущая из центра
круглая дыра, поднимающийся снизу край. `REVEALED` — моменты, когда очередная
обложка открыта целиком; по ним стоят засечки на полосе прокрутки и
переключается счётчик.

**Фотографии** вшиты в массив `PHOTOS`. Заменить:

```bash
sips -Z 900 -s format jpeg -s formatOptions 62 assets/photos/1.jpg --out /tmp/1.jpg
base64 -i /tmp/1.jpg
```

Первая идёт на вторую обложку, остальные — в карусель на третьей.

**Звук взрыва** — константа `BOOM_MP3`, туда же base64 от нового mp3.

**Тексты** — прямо в разметке обложек.
